Download Deploid

Deploid is an AI agent for DevOps that makes deployments easy and fun. With Deploid, you can quickly set up and manage your deployment environments.

Quick Install

You can install the latest version of Deploid with a single command:

curl -sSL https://github.com/divshekhar/deploid/releases/latest/download/install.sh | bash

Or if you prefer wget:

wget -qO- https://github.com/divshekhar/deploid/releases/latest/download/install.sh | bash

To install a specific version (e.g., v1.0.0):

curl -sSL https://github.com/divshekhar/deploid/releases/download/v1.0.0/install.sh | bash -s -- --version v1.0.0
Note: Always review scripts before running them with bash. You can download the script first and inspect it: 
curl -sSL https://github.com/divshekhar/deploid/releases/latest/download/install.sh -o install.sh
cat install.sh
bash install.sh

Installation Options

The installer script supports several options:

  • --version or -v: Specify the version to install (default: latest)
  • --directory or -d: Specify the installation directory
  • --yes or -y: Automatic yes to prompts
  • --help or -h: Show help message

Example with options:

bash install.sh --version v1.0.0 --directory ~/deploid-custom --yes

System Requirements

  • Python 3.6 or higher
  • pip (Python package manager)
  • bash shell

After Installation

After installation, you can run Deploid from anywhere by typing:

deploid

This will present you with a menu to:

  • Install tools (Git, Docker, OpenSSH, Sudo)
  • Set up repositories and deployments
  • Update existing deployments
